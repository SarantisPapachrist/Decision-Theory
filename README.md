# Decision-Theory
A project in Decision Theory using BreastTissue dataset

In this project i used the BreastTissue dataset in order to train 3 different classifiers and predict breast cancer. This dataset provides a set of biomedical measurements for each patient as well as information on whether the breast tissue is Carcinoma, Fibro-adenoma, Mastopathy, Glandular, Connective, Adipose. Each row in this file contains information for a different patient. More specifically the first task was about data preprocessing, where a normalization in [-1,1] was applied. After that three classifiers were trained with the 5-fold cross validation method. These three classifiers were Support Vector Machine, KNN and Naive Bayes. In addition with the classic evaluation metrics, Geometric Mean was added for better resutls. Finally, with the student t-test method the 4 most important attributes were found and only with them the classifiers were trained again. The results were observed and the comparison between the two dataset shoed that for better results we need all the measured characteristics of a patient.
